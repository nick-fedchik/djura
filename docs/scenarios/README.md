# Канонічні сценарії гри «Джура: початок шляху козака»

**Цільова аудиторія:** Діти 8–14 років та сімейний геймінг.  
**Художній стиль:** Золота доба української анімації («Київнаукфільм», Володимир Дахно, Давид Черкаський, Едуард Назаров).  
**Непорушні інваріанти:**
1. **Zero-Horror (I-3):** Ніякої крові чи темного насильства. Тільки веселий мультяшний слепстік: супротивники кумедно заплутуються, гублять шапки, падають у копиці сіна чи казан із виноградним соком і осоромлені тікають геть.
2. **Особиста дитяча мотивація героя:** Парубок Івась починає свій шлях через зрозумілу дитині образу від капосного хвалька-Чортика, а зустріч із Характерником Мамаєм навчає його самовладанню, шляхетності та козацьким таємницям.
3. **Чистота народної мови (Anti-Anglicism Invariant):** Жива, соковита українська мова без комп'ютерних чи боксерських кальок.
4. **Пізнавальне краєзнавство та дружба народів (Edutainment):** Кожен етап відкриває дитині справжнє багатство історії та культури споріднених вільних народів (козацька Україна, вільний Крим, Верховина гуцулів, башкирський Урал, священні ліси ерзян).
