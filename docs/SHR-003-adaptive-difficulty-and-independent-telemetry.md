# SHR-003: Адаптивна складність під гравця та незалежна телеметрія

- **Статус:** DRAFT
- **Дата:** 2026-10-24
- **Походження:** власник проєкту («будуть різні гравці, з різним віком і досвідом, гра має адаптуватися під їх інтерес»)
- **Трасується до:** [`SHR-001`](SHR-001-game-rules-as-verifiable-invariants.md) I-7

## Потреба
Гра для дітей 8+ і родин має сама підлаштовуватися під вік, досвід і інтерес кожного гравця, не вимагаючи від людей збирати чи надсилати дані. Оцінка складності проходження рівнів має бути вимірною й відтворюваною.

## Вимоги зацікавленої сторони
| № | Вимога |
|---|---|
| A-1 | Телеметрія збирається автоматично й локально, без дій гравця; нічого не копіюється й не надсилається |
| A-2 | Адаптація працює офлайн, детерміновано й відтворювано (той самий запис гри дає ті самі рішення) |
| A-3 | Адаптація має математичну основу: оцінка вміння з невизначеністю, цільова ймовірність успіху («потік»), розвідка інтересу |
| A-4 | Є засоби оцінки складності рівнів: статична (геометрія й склад) і емпірична (за даними гравців) |
| A-5 | Евристична оцінка досвіду гравців (Ollama) лише дорадча: її пропозиції проходять детерміновану перевірку меж і потрапляють до людини, а не у гру |
| A-6 | Приватність дітей: без персональних даних (імена, дата народження, пристрої), без мережі, дані видаляються видаленням однієї папки |
| A-7 | Захисні межі складності для віку (ніколи вище стелі для вікової групи) |
| A-8 | Багатовимірне полегшення для дуже слабких гравців ($K \to 0.5$): коли зниження самого коефіцієнта $K$ до нижньої межі `K_MIN = 0.5` недостатньо для досягнення цільової ймовірності успіху $0.70\text{–}0.78$ (емпірично дає $\approx 0.50$), гра задіює додаткові м'які важелі без порушення правил рівнів — довший перепочинок ворогів, раніший прихід союзників (від 1-го зібраного ядра), ширше вікно бонусів (підківки Вакули / Характерник) та плавніше зниження темпу переслідування |

## Ризики (рецензент)
1. **Телеметрія неповнолітніх.** Навіть локальна та анонімна, вона потребує згоди батьків при будь-якому підключенні мережі (GDPR-K, COPPA); поки мережі немає, ризик зведений до локальних файлів.
2. **Перенавчання під одного гравця.** Одна коробка на кількох дітей змішує профіль; потрібен вибір профілю (T-022).
3. **Модель з Ollama не детермінована.** Тому вона не бере участі в ігровому циклі.
4. **«Тихе» спрощення.** Дитина може не помітити, що гра її підлаштовує; це прийнятно, якщо захисні межі не роблять гру безглуздо легкою.
