## 4. Пропозиції

1. **Гілки та злиття.** Агенти працюють у гілках `agent/<ім'я>/<задача>`, у `main` потрапляє лише злиття зі зеленим CI.
   *EARS:* The repository SHALL NOT accept direct pushes to `main` from automated agents. *Приймання:* налаштовано захист гілки `main` на GitHub, пуш агента в `main` відхиляється.
2. **Атрибуція.** Додати `Co-Authored-By:` у кожен коміт, створений агентом (уже вимагає інструмент, але в історії відсутнє).
3. **CI (ORG-02).** Мінімальний `.github/workflows/test.yml`: встановлення Godot 4.7.2 headless, `tools/run_tests.sh`, `gdparse` на змінених `.gd`.
   *EARS:* WHEN a pull request is opened, the CI SHALL run `tools/run_tests.sh` and fail the check on a non-zero exit code. *Приймання:* червоний тест блокує злиття (перевірити навмисно зламаним тестом).
4. **Прибрати корінь (ORG-03).** Перенести генератори звуку у `tools/audio/`, видалити кореневий `main.tscn`, закрити T-008.
5. **Унікальні ID задач (ORG-04).** Перейменувати другий `T-021`, додати тест `tools/test_tools.py`, що шукає дублікати ID у `docs/TASKS.md`.
6. **`ASSETS.md` (ORG-05).** Таблиця: файл, джерело (Meshy/власний), дата, умови використання, чи входить у збірку.
7. **Індекс документів (ORG-06).** `docs/README.md` на 15 рядків з посиланнями.
