# Бестіарій гри «Джура: початок шляху козака»
## Темні сили: Потвори, Загарбники, Нечисть, Боси, Суперзлодії

Цей каталог містить структурований архів вихідних 2D/3D асетів темних сил та супротивників гри.

### Структура підкаталогів:
* `minions/`: Рядова нечисть:
  * `vohnyk/`: Купальський Вогник (палій ґнотів, таймер 7.0 с).
  * `chort/`: Чортик-крутько (крадій вогневих ядер, липка смола).
* `elites/`: Елітні вороги та інженери:
  * `vidma/`: Відьма Солоха (проводирка навали, магічні щити).
  * `moskal/`: Окупаційні війська (Шиш, Приказний Дяк, Опричник, Пихатий Воєвода, Генерал).
* `regional/`: Регіональний бестіарій народів:
  * `erzya/`: Куйгорож (вогняний сокіл-сова), Бука (копиця-маскувальник).
  * `bashkir/`: Шуралє-підпалювач (довгі пальці), Мала Бічура (червона сорочка).
* `superbosses/`: Гранд-боси великих етапів:
  * `vij/`: Підземний Вій (каземати Хотина).
  * `tsar_mortar/`: Цар-Мортира на колісниці з Генералом.
  * `azhdaha/`: Змій-Аждаха (печери Тавриди).
  * `temnyk/`: Панцерний Залізний Темник.

Повний реєстр та статус кожного активу зафіксовано в [docs/PANTHEON_AND_BESTIARY.md](res://docs/PANTHEON_AND_BESTIARY.md).
