# Пантеон гри «Джура: початок шляху козака»
## Світлі сили: Головний Герой, Наставники, Союзники, Богатирі-Титани

Цей каталог містить структурований архів вихідних 2D/3D асетів світлих персонажів гри.

### Структура підкаталогів:
* `heroes/djura/`: Головний Герой (15 років, спадкоємець Котигорошка).
  * `2d/`: пошарові скетчі, ракурси, портрет, спрайт-аркуш, `SpriteFrames` (`.tres`).
  * `3d/`: .blend сцени, .glb меші з ригом та текстурами.
* `mentors/`: Мудрі наставники-вчителі:
  * `mamay/`: Козак-Характерник Мамай (Запорозька Січ).
  * `tiushtian/`: Цар-деміург Тюштян (Ерзянь Мастор, ріг Торама).
  * `sesen/`: Сивий Сесен (Башкортостан, флейта курай).
* `allies/`: Друзі та побратими Джури:
  * `qirimli/`: Батир Киримли Їгіт із Соколом (Крим).
  * `hutsul/`: Карпатський Гуцул із Барткою (Карпати).
  * `mavka/`: Степова та Лісова Мавка.
  * `vakula/`: Коваль Вакула (Чарівні Підківки).
* `titans/`: Прадавні велетні Котигорошка (Асисти виключно проти Суперзлодіїв):
  * `vernydub/`: Дубодер (стихія лісу й барикад).
  * `vernyhora/`: Вертигора (стихія скель і броні).
  * `krytyvus/`: Крутивус (стихія хвиль і вихорів).

Повний реєстр та статус кожного активу зафіксовано в [docs/PANTHEON_AND_BESTIARY.md](res://docs/PANTHEON_AND_BESTIARY.md).
