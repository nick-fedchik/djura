# ⚔️ Козак Джура: Вогняні Ядра Січі (`Geek-Jack`)

> **Українська фольклорно-історична аркада у стилі золотого віку «Київнаукфільму» (Володимир Дахно, Едуард Кірич, Давид Черкаський) та класичної аркадної фізики *Bomb Jack* на рушії Godot Engine 4.x.**

Юний 15-річний козак-зброєносець **Джура** (з традиційним чубом **«оселедцем»-айдаром** та крилатою киреєю від Козака Мамая) разом із побратимами — **Карпатським Гуцулом з барткою** та **кримськотатарським їгітом Киримли з луком і степовим Соколом** — рятує вогняні порохові ядра від гоголівських чортиків, відьми Солохи, купальських вогників та царських стрільців-загарбників!

---

## 🚀 Швидкий старт за 2 хвилини (Як завантажити рушій і запустити гру)

Гра не потребує жодних важких текстур чи зовнішніх залежностей — **уся графіка та анімація генеруються процедурно в реальному часі на GPU/Canvas (`_draw` + GLSL шейдери)**, а розмір репозиторію мінімальний!

### Крок 1. Встановіть безкоштовний рушій **Godot Engine 4.x** (версія 4.3+ / 4.7)

Оберіть зручний спосіб для вашої ОС (потрібна звичайна **Standard version**, без .NET):

* **🌐 Офіційний сайт (Windows / macOS / Linux — один файл без інсталяції):**
  Завантажте архів із [https://godotengine.org/download/](https://godotengine.org/download/) та розпакуйте бінарник `godot`.
* **🐧 Linux (Ubuntu / Debian / Mint / Fedora):**
  ```bash
  # Через Snap або Flatpak (найсвіжіша версія Godot 4):
  sudo snap install godot-4
  # Або завантажте прямий бінарник у ~/bin чи /usr/local/bin:
  wget -qO godot.zip https://github.com/godotengine/godot/releases/download/4.3-stable/Godot_v4.3-stable_linux.x86_64.zip
  unzip godot.zip && chmod +x Godot_v4.3-stable_linux.x86_64 && sudo mv Godot_v4.3-stable_linux.x86_64 /usr/local/bin/godot
  ```
* **🍎 macOS (через Homebrew):**
  ```bash
  brew install --cask godot
  ```
* **🪟 Windows (через Winget або Scoop):**
  ```bash
  winget install GodotEngine.GodotEngine
  ```

### Крок 2. Клонуйте репозиторій та запустіть гру

```bash
git clone https://github.com/nick-fedchik/geek-jack.git
cd geek-jack

# Варіант А: Миттєвий запуск гри з термінала
godot --path .

# Варіант Б: Відкрити проєкт у візуальному редакторі Godot
godot -e --path .
```
*(Якщо ви відкрили Godot через ярлик на робочому столі: натисніть **«Import»**, оберіть файл `project.godot` у папці `geek-jack` і натисніть **«Run Project» (F5)**).*

## 🤖 Як стати Вайб-Кодером гри (Vibe-Coder's Onboarding Guide)

Цей проєкт ідеально створений для **вайб-кодингу (Vibe Coding)** з використанням ШІ-агентів (**Google Antigravity**, **Claude Code**, **Cursor**, **GitHub Copilot**, **Windsurf**)!

Чому тут надзвичайно легко вайб-кодити:
1. **100% процедурна векторна графіка на коді (`_draw()`):** вам не потрібно малювати спрайти у Photoshop чи Aseprite! Просто опишіть ШІ-агенту зовнішність персонажа, танець чи спецефект українською мовою — і агент напише GDScript-код малювання у стилі «Київнаукфільм».
2. **Процедурний синтез звуку та музики на Python (`generate_*.py`):** усі звукові ефекти й козацька музика генеруються математично через Python-скрипти у `assets/audio/`.
3. **Автоматичні безголові тести за 2 секунди (`test/test_levels.gd`):** ШІ-агент сам перевіряє свій код без запуску вікна командою:
   ```bash
   godot --headless --script test/test_levels.gd
   ```

### 🛠️ Покроковий рецепт для Вайб-Кодера:

1. **Зробіть Fork** цього репозиторію на GitHub та клонуйте його собі.
2. **Відкрийте папку `geek-jack` у вашому улюбленому ШІ-середовищі** (Antigravity CLI, Cursor, VS Code + Copilot або Claude Code).
3. **Дайте ШІ-агенту контекст**, попросивши його прочитати документацію проєкту:
   * [`docs/MEMO_FOLKLORE_CHARACTERS.md`](docs/MEMO_FOLKLORE_CHARACTERS.md) — бестіарій ворогів, союзників, супергероїв та артефактів.
   * [`docs/MEMO_BOXING_SUPERHEROES_PROGRESSION.md`](docs/MEMO_BOXING_SUPERHEROES_PROGRESSION.md) — система боксерських суперударів та Бойового Гопака.
   * [`CONTRIBUTING.md`](CONTRIBUTING.md) — готові ідеї та промпти для вайб-кодингу.
4. **Напишіть ваш промпт природною мовою!** Наприклад:
   > *«Додай на 4-му рівні боса Конотопську Відьму Явдоху Зубиху згідно з `docs/MEMO_FOLKLORE_CHARACTERS.md`, яка насилає вихор, та додай тест у `test/test_levels.gd`»*
   або:
   > *«Додай супергероя Олексу Довбуша, який приходить на допомогу Гуцулам і розколює скелі золотою барткою!»*
5. **Перевірте автотести та надішліть Pull Request (PR):**
   ```bash
   godot --headless --script test/test_levels.gd
   ```

## 📂 Карта архітектури проєкту (Де що лежить)

```text
geek-jack/
├── project.godot                  # Головний конфіг Godot 4 (2K 16:9 viewport, мапінг клавіш та геймпада)
├── main.tscn                      # Головна сцена гри
├── scenes/                        # Сцени вузлів (Player, HUD, Enemy, HutsulAlly, QirimliAlly, Bombs)
├── scripts/
│   ├── game_manager.gd            # Логіка рівнів 1..5, прогресивний спавн союзників, підказки ударів
│   ├── player.gd                  # Фізика Джури, крилата кирея, Бойовий Гопак, удари Кличків/Усика, _draw()
│   ├── enemy.gd                   # Вороги: Чортик, Відьма, Вогник, Москаль + система втоми й перепочинку
│   ├── hutsul_ally.gd             # Союзник Карпатський Гуцул з барткою та переможний танець «Аркан»
│   ├── qirimli_ally.gd            # Союзник Киримли з луком, степовим Соколом та танцем «Хайтарма»
│   ├── background_visual.gd       # Історичні панорами 5 рівнів (Хортиця, Диканька, Кам'янець, Батурин, Крим)
│   ├── story_cards.gd             # Анімовані сюжетні слайди-казки перед кожним рівнем
│   └── vakula_horseshoe.gd        # Чарівні золоті підківки Коваля Вакули (прострибування крізь балки)
├── shaders/
│   └── kyivnaukfilm_ink.gdshader  # GLSL-шейдер теплого целулоїдного контуру та паперу «Київнаукфільм»
├── docs/                          # Проєктні меморандуми, дизайн персонажів, супербосів та прогресії
└── test/
    └── test_levels.gd             # Автоматичний headless-тест усіх 5 рівнів, фізики, союзників та бою
```
